# Desafio Matemático

Aplicativo desenvolvido em .NET MAUI para o Exercício Prático 02 da disciplina de desenvolvimento mobile.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Dificuldades fácil (1 a 10), médio (1 a 50) e difícil (1 a 100).
- Dez questões por partida com barra de progresso.
- Timer de 30 segundos com alerta visual nos segundos finais.
- Pontuação baseada na dificuldade e bônus pelo tempo restante.
- Validação de entrada numérica e feedback imediato.
- Resumo final com pontuação, acertos, erros, tempo médio e classificação.

## Executar

Abra `MathGame.slnx` no Visual Studio 2026 com a carga de trabalho .NET MAUI instalada. Selecione Windows ou um emulador Android e execute o projeto `MathGame`.
